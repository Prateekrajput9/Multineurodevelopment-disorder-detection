# NOTES:
# - EEGLAB preprocessing (DS-1 MODE A) requires MATLAB + EEGLAB. 
#   This is NOT reproducible in pure Python without a MATLAB license.
#   The CleanLine plugin and ADJUST plugin are MATLAB-only.
#   DS-1 default mode = B (use provided preprocessed data).
#
# - DS-2 preprocessing IS fully reproducible in Python (scipy, pywavelets).
#
# - SMVMD is implemented from scratch in src/smvmd.py based on:
#   [24] Liu & Yu, "Successive Multivariate Variational Mode Decomposition",
#   Multidimensional Systems and Signal Processing, 2022.
#   No existing Python SMVMD library is available; this is a custom implementation.
#
# - Bayesian hyperparameter optimization is done with scikit-optimize (skopt)
#   or bayesian-optimization. The paper uses MATLAB R2023a Classification Learner.
#   EXACT reproduction of MATLAB's internal optimizer is not possible in Python.
#   This is documented in docs/reproducibility_notes.md.
